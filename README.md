# homebrew-tap

Homebrew tap for [leech2](https://github.com/larsewi/leech2).

```sh
brew install larsewi/tap/leech2
```

This installs the `lch` CLI, `libleech2.dylib`, `leech2.h`, a `leech2.pc` for
pkg-config, and the man pages. macOS only. On Linux use the `.deb` or `.rpm`
from the [releases](https://github.com/larsewi/leech2/releases).

The formula tracks the prebuilt macOS tarballs from each leech2 release. Do not
edit the version or checksums by hand.
